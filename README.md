# TripleTen web_project_expenses

Nome do Projeto
Rastreador de Despesas

Descrição
Página web interativa onde se configura um orçamento, adiciona-se e remove despesas de diferentes categorias e visualiza-se algumas estatísticas sobre esses gastos. Aprendizado em continuar o desenvolvimento de uma aplicação já iniciada por outro desenvolvedor, concentrando-se em definir a lógica de funções e operações com variáveis para torná-la dinâmica para o usuário.

Tecnologias e técnicas utilizadas
Javascript: variáveis, condicionais, loops, arrays e operações.
